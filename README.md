# Tabrizi Bakery Website

A premium heritage bakery website redesign built with Next.js, TypeScript and Tailwind CSS.

## Overview

A luxury editorial-style website concept for Tabrizi Bakery, a Persian family-owned bakery established in Watertown, Massachusetts.

The project focuses on:

- Heritage brand storytelling
- Premium food presentation
- Modern frontend architecture
- Responsive user experience
- Performance optimization
